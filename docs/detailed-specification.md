# 経費管理アプリ 詳細設計仕様書

> 追加要望を反映した詳細設計（国税庁ベースの記帳要件対応）

---

## 1. 追加要望を反映した全体像（最新版）

### 入力（音声/手入力）
- **取引種別**: 売上 / 経費 をAIが自動判定（迷うときは質問）
- **AIが抽出**: 日付・金額・取引先・内容（摘要）・勘定科目（freee寄せ）
- ユーザーが確認 → 必要なら修正 → 確定

### 証憑（レシート/請求書）
- 履歴の各行に **「証憑アップロード」ボタン**
- PDF/画像をアップロード → Google Driveの所定フォルダへ自動保存
- 保存した fileId/URL をスプレッドシートに自動記録
- 履歴画面から **「証憑を見る」** で開ける（Driveリンク）

### 会計士共有
- DBスプレッドシート（自分用） → **経費一覧だけ** を会計士共有用スプレッドシートへ **確定時に即同期**（GAS）

## 2. 国税庁ベースの記帳要件

### 最低限必要な記載項目（国税庁例示）

| 項目 | 説明 |
|------|------|
| 取引年月日 | 取引が発生した日付 |
| 相手方の名称 | 売上先・仕入先などの名称 |
| 金額 | 取引金額 |
| 日々の売上・仕入・経費の金額等 | 簡易なまとめ記載もOK |

> **参照**: 国税庁の記帳・帳簿等の保存制度

### 実務的に「ほぼ必須」になる追加項目
- 勘定科目（freee寄せで会計士が処理しやすい）
- 支払方法（現金/口座/カード）
- 証憑リンク（後で説明できる形）

## 3. 会計士共有用「経費一覧」シート定義

### ヘッダー（最小セット）

| No. | カラム名 | 英語名 | 必須 | 説明 |
|-----|----------|--------|------|------|
| 1 | 取引日 | date | ○ | 取引が発生した日付 |
| 2 | 取引先 | vendor | ○ | 相手方の名称 |
| 3 | 摘要（内容） | description | ○ | 取引の内容・詳細 |
| 4 | 金額 | amount | ○ | 取引金額（税込） |
| 5 | 勘定科目 | account_title | ○ | freee寄せの科目名 |
| 6 | 支払方法 | payment_method | ○ | 現金/口座/カード |
| 7 | 証憑リンク | receipt_url | - | Drive URL（任意） |
| 8 | メモ | memo | - | 補足情報（任意） |

> **注意**: 「取引日・相手先・内容・金額」は国税庁の記帳例に沿う中核項目

### 税区分について
- **MVPでは列は用意するけど入力必須にしない**
- 将来インボイス/消費税対応する場合に備えて「後でONにできる設計」
- 年商200万円規模だと免税事業者の可能性が高く、最初からガチ対応は不要

## 5. Google Drive 証憑保存の仕様

### フォルダ設計

```
SkyBlueEarthJapan_証憑/
├── 2026/
│   ├── 01/
│   │   ├── 2026-01-24_12000_Amazon_消耗品費.pdf
│   │   └── 2026-01-25_5000_スタバ_接待交際費.jpg
│   ├── 02/
│   └── ...
└── 2027/
    └── ...
```

### ファイル命名規則

```
{日付}_{金額}_{取引先}_{勘定科目}.{拡張子}
```

例: `2026-01-24_12000_Amazon_消耗品費.pdf`

### アップロード導線

| 状態 | 表示 | アクション |
|------|------|------------|
| 証憑なし | 「証憑アップロード」ボタン | PDF/画像選択 → Drive保存 → シートにリンク保存 |
| 証憑あり | 「証憑を見る」ボタン | Driveリンクを開く |

### 共有の考え方

| 運用パターン | 設定 |
|--------------|------|
| 会計士にも証憑を見せる | Drive側のフォルダ/ファイルに閲覧権限を付与（会計士のGoogleアカウント必要） |
| 見せない | 同期時にreceipt_url列をマスキング（空にする） |

## 6. 売上の自動認識設計

### 売上と経費の違い

| 項目 | 経費 (expense) | 売上 (revenue) |
|------|----------------|----------------|
| type | expense | revenue |
| 勘定科目 | 消耗品費、旅費交通費 など | 売上高 |
| 支払/入金方法 | cash / bank / card | cash / bank / payment_service |
| 証憑 | レシート、領収書 | 請求書、入金明細 |

### AI判定のポイント
- キーワード: 「売った」「入金」「受注」→ revenue
- キーワード: 「買った」「支払い」「払った」→ expense
- 迷う場合はユーザーに質問

### 売上の勘定科目（初期）
- **売上高**（freee寄せ）

## 7. 住民税・所得税の扱い（方針）

### MVP方針
> 「税金計算は会計士がやるので、まず経費一覧が出ればOK」

### 将来の分析ページ用（参考情報）

#### 所得税
- 速算表（5%〜45%の7段階）
- 復興特別所得税（2.1%）
- 参照: 国税庁「No.2260 所得税の税率」

#### 住民税（東京都の場合）
| 項目 | 税率/金額 |
|------|-----------|
| 所得割（都民税） | 4% |
| 所得割（区市町村民税） | 6% |
| **所得割合計** | **10%** |
| 均等割 | 定額 |
| 森林環境税 | 年額1,000円 |

> **注意**: 概算を出すなら「地域設定（都道府県/市区町村）」を持つのが筋だが、MVPでは不要

## 8. 確定した設計方針

| 項目 | 決定 | 理由 |
|------|------|------|
| 税区分 | 列は用意、入力必須にはしない | 後で拡張可能に |
| 証憑のAI読み取り | しない | まずは"保存＆リンク紐付け"のみ |
| 同期タイミング | 確定時に即同期 | リアルタイム性重視 |
| 再同期 | 「万一の再同期」ボタンも用意 | 障害対応用 |
| 対話モード | MVPから入れる | 不足項目を質問で埋める |
| 証憑の会計士共有 | 設定で選択可能 | 運用に応じて切替 |
