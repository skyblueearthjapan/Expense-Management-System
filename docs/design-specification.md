# 経費管理アプリ 設計仕様書

> 音声×AI×スプレッドシートDBの、個人事業専用・経費管理アプリ

---

## 1. 目的とゴール

このアプリが解決すること：

- **音声 or 手入力** → AIが取引を構造化（日付/金額/相手/内容/勘定科目/税区分など）
- AIの推定結果を **確認・修正して確定**（監査ログも残す）
- スプレッドシート（DB）に**自動記録**し、履歴閲覧
- 月次の **売上・経費・利益** を可視化
- 年間の見込みから **所得税/住民税の概算** を表示（ルールは設定で調整）
- 会計士共有用に、DBから **経費一覧だけ** を別スプレッドシートへ自動転送

### C. 分析（ダッシュボード画面）

#### 今月サマリー
- 売上
- 経費

## 3. 主要フロー

### 入力フロー（経費例）

```
1. ユーザー：「昨日、Amazonで1万2千円、事務用品を買った」

2. AI：構造化（推定）
   - 日付=昨日
   - 金額=12000
   - 取引先=Amazon
   - 内容=事務用品
   - 勘定科目=消耗品費（候補：消耗品費/通信費/雑費…）

3. AI：「消耗品費で良い？」→ OK / 修正

4. 確定したらDBシートへ書き込み（編集履歴も残す）

5. 会計士共有用シートへ同期（リアルタイム or 5分毎など）
```

## 5. AI設計（分類と聞き返し）

### AIにやらせること（MVP）
- 音声→文字起こし
- 文字列→取引データの抽出（JSON）
- 勘定科目推定（候補を複数提示）
- 不足情報の質問（例：「日付はいつ？」「これは売上？経費？」）

### 勘定科目推定のコツ
- いきなり1個に決め打ちしない
- **第1候補＋候補2〜3＋理由** を出す
- 取引先辞書（Amazon→消耗品費多い等）を効かせる
- ユーザーの修正を学習（=辞書更新）して、次回から当てる

## 8. 設計方針（確定事項）

| No. | 論点 | 決定 |
|-----|------|------|
| 1 | 売上も音声入力の対象にする？ | する |
| 2 | 証憑（レシート）はMVPで必須？ | 任意、後で追加 |
| 3 | 税区分（課税/非課税など）は最初からやる？ | 後回し可 |
| 4 | 取引の最低必須項目 | 日付・金額・内容でOK |
| 5 | 勘定科目の初期セット | freee寄せで進める |
| 6 | 同期タイミング | 確定時に即同期 |
| 7 | 編集のルール | 確定後編集は「修正履歴を必ず残す」 |
| 8 | 入力の会話 | AIが質問する"対話モード"を最初から入れる |
| 9 | 予測税額 | 所得税＋復興特別所得税（2.1%）までやる |
| 10 | 住民税 | 概算（標準10%＋均等割は設定）で良い |

## 10. 勘定科目一覧（freee準拠）

青色申告で経費として計上可能な主な勘定科目：

| 勘定科目 | 内容例 |
|----------|--------|
| 租税公課 | 個人事業税、固定資産税、自動車税、印紙税等 |
| 荷造運賃 | 商品発送の送料、梱包材 |
| 水道光熱費 | 事業所の電気・水道・ガス代 |
| 旅費交通費 | 出張の交通費・宿泊費・ガソリン代 |
| 通信費 | 電話・インターネット料金、切手代 |
| 広告宣伝費 | Web広告費、チラシ制作費 |
| 接待交際費 | 取引先との飲食費・贈答品費 |
| 損害保険料 | 事業用保険の保険料 |
| 修繕費 | 建物・設備等の修理費 |
| 消耗品費 | 文房具、事務用品（10万円未満） |
| 減価償却費 | 高額資産（10万円以上）の減価償却費 |
| 福利厚生費 | 従業員の健康診断費用等 |
| 給料賃金 | 従業員への給与支払い |
| 外注工賃（外注費） | 外部業者への支払い |
| 支払利息 | 借入金の利息など |
| 地代家賃 | 事務所・店舗の賃借料 |
| 貸倒損失 | 売掛金の回収不能損失 |
| 雑費 | 上記に該当しない少額の経費 |

> **注**: 勘定科目は法律で名称や分類が厳密に決まっているわけではなく、事業の実態に即して適切な科目名を付けることが重要
